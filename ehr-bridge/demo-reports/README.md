# Reports you can add

Three fictional reports for Sarah Mitchell, patient **PT-DEMO-SARAH**. Each has a PDF attachment and matching native JSON.

| Report | Sign in as | Files |
| --- | --- | --- |
| Routine checkup | Memorial: `emily@bridge.demo` | `01-memorial-checkup.pdf` / `.json` |
| Blood test | Valley: `daniel@bridge.demo` | `02-valley-blood-test.pdf` / `.json` |
| Chest X-ray narrative | Valley: `daniel@bridge.demo` | `03-valley-chest-xray.pdf` / `.json` |

1. Find **PT-DEMO-SARAH** and select **Upload visit**.
2. Open **Native payload** and paste the contents of the matching JSON file.
3. Attach its PDF using **Attach images or reports**, then upload.

The PDF can also be attached to a visit you enter manually. The X-ray report contains a fictional narrative only; no X-ray image is included. No records have been uploaded automatically.
